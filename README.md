# سایت کارزار توقف قطع درختان

## راه‌اندازی با GitHub Pages و Supabase

### ۱. ساخت پروژهٔ Supabase

در Supabase یک پروژه بسازید.

سپس در بخش SQL Editor این کد را اجرا کنید:

```sql
create table public.signatures (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(trim(name)) between 1 and 80),
  created_at timestamptz not null default now()
);

alter table public.signatures enable row level security;

create policy "Anyone can read signatures count"
on public.signatures
for select
to anon
using (true);

create policy "Anyone can submit a signature"
on public.signatures
for insert
to anon
with check (
  char_length(trim(name)) between 1 and 80
);
```

### ۲. گرفتن اطلاعات اتصال

از تنظیمات API پروژهٔ Supabase، مقدار URL و کلید anon/publishable را بردارید.

در `config.js` قرار دهید:

```js
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY";
```

کلید `service_role` یا secret را هرگز در سایت قرار ندهید.

### ۳. انتشار

سه فایل زیر را در ریشهٔ repository گیت‌هاب قرار دهید:

- `index.html`
- `style.css`
- `script.js`
- `config.js`

سپس از Settings → Pages، منبع انتشار را روی branch موردنظر قرار دهید.

پس از انتشار، کاربران اطلاعاتشان را در Supabase ثبت می‌کنند و شمارنده از دیتابیس خوانده می‌شود.
